## Описание

Учебный интернет-магазин необычных студенческих товаров. Предметная область, изображения и структура страниц взяты из КР №1. Интерфейс выполнен отдельно на Bootstrap.

В каталоге шесть товаров: рюкзак, пенал, личный портал, личная лавочка, защита от внешних воздействий и побег с пар. Карточки написаны непосредственно в HTML. Все ссылки «Подробнее» ведут на одну статическую страницу `product.html` с товаром «Побег с пар», как в КР №1. В форме заявки товар выбирается вручную.

Проект охватывает практические работы №9–11. Практика №11 завершает КР №2 и содержит постановку следующей КР №3, которая выполняется в отдельном репозитории.

## Запуск

Откройте `index.html` в браузере. Сборка, npm и интернет не требуются.

При необходимости из папки проекта можно запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Адрес: `http://localhost:8000`.

## Подключение Bootstrap

Используется **Bootstrap 5.3.8**, подключённый локально:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
```

В начале практики №9 использовался CDN. В итоговой версии выполнено дополнительное задание из практики №11: файлы фреймворка размещены в `vendor/bootstrap/`. CSS и JS одной версии; Bundle включает Popper. Собственные стили подключены после Bootstrap.

[Официальная загрузка Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/download/). Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`.

## Практическая работа №9

- Подключены Bootstrap и `css/custom.css`.
- Созданы шапка, навигация, hero, преимущества, популярные товары и подвал.
- `container-fluid` задаёт фон hero на всю ширину; вложенный `container` ограничивает содержимое.
- Hero использует `row g-4` и `col-12 col-lg-6`. Справа расположена карусель из шести фотографий товаров без названий и цен. Стрелки и индикаторы переключают слайды средствами Bootstrap; автоматическое перелистывание выключено.
- Преимущества используют `col-12 col-md-4`.
- Карточки используют `col-12 col-md-6 col-lg-4`: один столбец на телефоне, два на планшете, три на больших экранах.
- Отступы, цвета и выравнивание заданы Bootstrap utility-классами.

## JavaScript в проекте

`bootstrap.bundle.min.js` — готовая библиотека, необходимая по ТЗ для раскрытия меню, модального окна, вкладок, accordion и карусели. Эти компоненты подключаются HTML-атрибутами `data-bs-toggle` и `data-bs-target`.

Собственный `js/main.js` содержит только базовую обработку форм по образцу КР №1: отменяет стандартную отправку, проверяет HTML-ограничения, очищает форму и показывает сообщение. Реального backend нет, контактные данные не отправляются и не сохраняются.

Каталог и общая страница товара полностью заданы HTML-разметкой. JS не создаёт карточки, не меняет описание товара, не фильтрует каталог и не рассчитывает стоимость.

## Проверка перед сдачей

1. Откройте главную: проверьте hero, преимущества, популярные товары и якорные ссылки. Переключите шесть товаров в карусели стрелками и индикаторами; проверьте переход с последнего слайда на первый.
2. Откройте каталог: видны все шесть карточек. Все кнопки «Подробнее» ведут на одну `product.html`.
3. На странице товара проверьте статическое описание «Побег с пар», изображение, цену, badge и таблицу. Переключите вкладки.
4. Откройте заявку: вручную выберите товар, заполните имя, e-mail, телефон и согласие. Телефон вводится как 10 цифр без +7. Проверьте обязательные поля и формат e-mail средствами браузера.
5. Отправьте заполненную форму: появится учебное сообщение, данные не отправляются на сервер. «Очистить» сбрасывает поля и убирает сообщение.
6. Нажмите «Заказать» на любой карточке: открывается общая быстрая заявка с ручным выбором товара. Проверьте отправку и закрытие крестиком, кнопкой и Escape.
7. На странице контактов проверьте форму обратной связи и раскрытие вопросов accordion.
8. Проверьте все страницы на ширинах **375, 768, 1024 и 1440 px**: перестройку карточек, мобильное меню, формы, таблицу, модальное окно и подвал.
9. Пройдите ссылки, кнопки и поля клавишей Tab: фокус виден, поля подписаны.

## Краткие пояснения для защиты

- Сетка Bootstrap состоит из 12 колонок. `col-lg-4` занимает треть строки; `col-md-6` — половину. Колонки помещаются в `row`, а строки — в контейнер.
- `g-4` задаёт промежутки между колонками и строками. `my-5`, `p-4`, `mb-3` управляют отступами.
- `h-100`, `d-flex flex-column` и `mt-auto` помогают выровнять карточки по высоте и расположить кнопки снизу.
- `data-bs-target="#orderModal"` связывает кнопку с общим модальным окном по его `id`. Открытие и закрытие выполняет Bootstrap.
- `required`, `type="email"`, `pattern` и `minlength` проверяются браузером. `preventDefault()` отменяет реальную отправку учебной формы.
- `custom.css` дополняет Bootstrap стилями изображений и фокуса; основная вёрстка выполнена классами фреймворка.
