## Описание

Учебный магазин необычных студенческих товаров. Предметная область, шесть товаров и изображения сохранены из КР №1; интерфейс реализован отдельно на Bootstrap. В каталоге представлены рюкзак, пенал, личный портал, личная лавочка, защита от внешних воздействий и побег с пар.

Проект охватывает практические работы №9–11. КР №3, постановка которой приведена в практике №11, выполняется позднее в отдельном репозитории на основе HTML/CSS-проекта КР №1.

Это статический frontend-проект. Формы проверяют данные в браузере и показывают результат. Контакты не сохраняются и не отправляются на сервер; реальные оплата и доставка не реализованы.

## Запуск

Откройте `index.html` в браузере. Сборка, npm и подключение к интернету не требуются.

При необходимости можно запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Подключение Bootstrap

Используется **Bootstrap 5.3.8**, подключённый локально:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
```

При начале практики №9 использовался CDN. В итоговой версии выполнено дополнительное задание из практики №11: CSS и JS находятся в `vendor/bootstrap/`, обращения к CDN отсутствуют. Версии CSS и JS совпадают. Bundle включает Popper для выпадающего меню. Собственный CSS загружается после фреймворка.

[Официальная загрузка Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/download/). Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`.

## Практическая работа №9

- Подключены Bootstrap и `css/custom.css`.
- Созданы шапка, единая навигация и подвал.
- Hero использует `container-fluid` для фоновой области и `container` для ограничения контента; внутри — `row g-4` и `col-12 col-lg-6`.
- Преимущества используют `col-12 col-md-4`: один столбец на телефоне, три с 768 px.
- Популярные товары используют `col-12 col-md-6 col-lg-4`: один, два и три столбца.
- Отступы, выравнивание, цвета и размеры задаются utility-классами Bootstrap.

## Как проверить

1. На главной проверьте hero, преимущества, популярные товары и якорные ссылки в меню «Разделы».
2. Откройте каталог: выберите «Необычные решения», цену до 2000 и нажмите «Применить». Останутся портал и защита. Поиск «ПОРТАЛ» оставит один товар.
3. Введите отсутствующее название — появится сообщение о пустой выдаче. Нажмите «Сбросить»: вернутся все шесть товаров. Сортировка «Сначала дороже» ставит побег с пар первым.
4. Откройте «Подробнее» у любого товара: меняются название, изображение, описание, цена, характеристики и ссылка на заявку. Переключите вкладки.
5. Нажмите «Оформить заявку»: товар уже выбран. Измените количество, проверьте сумму. Для телефона вводятся 10 цифр без +7. Пустые обязательные поля, неверный e-mail, короткий телефон и количество вне 1–10 не проходят проверку.
6. Заполните форму и согласие. Появится сообщение с выбранным товаром, количеством и суммой; данные не отправляются. «Очистить» убирает сообщение и возвращает начальные значения.
7. В каталоге нажмите «Заказать»: откроется Bootstrap-modal с выбранным товаром. Проверьте валидацию, отправку, закрытие крестиком, кнопкой и Escape. Повторное открытие очищает контакты.
8. На странице контактов откройте вопросы accordion и проверьте форму обратной связи.
9. Проверьте ширины **375, 768, 1024 и 1440 px**: меню, hero, сетку, формы, таблицу, модальное окно и подвал. На малом экране меню раскрывается кнопкой.
10. Пройдите элементы клавишей Tab. У ссылок, кнопок и полей есть видимый фокус, у полей — `label`, у изображений — `alt`. После успешной проверки фокус перемещается на сообщение результата.

26 октября 2026 года выполнена браузерная проверка пяти страниц на четырёх указанных ширинах. Проверены все шесть переходов товар → заявка, фильтры и сортировка, валидация и сброс форм, расчёт суммы, модальное окно, Escape, вкладки и accordion. Переполнения по ширине и ошибок JavaScript не обнаружено. Проверены локальные ссылки, якоря, уникальность `id` и подписи полей.

## Краткие пояснения для защиты

- Bootstrap использует 12 колонок. `col-lg-4` занимает 4/12 строки, поэтому в ряд помещаются три товара. Классы колонок находятся внутри `row`.
- `container` ограничивает ширину и центрирует содержимое; `container-fluid` нужен для фона hero на всю ширину. `g-4` задаёт промежутки между колонками и строками.
- `h-100` и `d-flex flex-column` выравнивают высоту карточек, а `mt-auto` прижимает цену и действия к нижней части.
- `data-bs-toggle` и `data-bs-target` включают готовый компонент Bootstrap и связывают его с элементом по `id`.
- Параметр `?product=portal` передаёт идентификатор товара между страницами. `products.js` содержит его данные; `main.js` подставляет их через `textContent`. Неизвестный идентификатор показывает предупреждение и рюкзак по умолчанию.
- HTML-атрибуты `required`, `type`, `pattern`, `min`, `max` и `step` задают ограничения формы. При ошибке поле получает `aria-invalid` и Bootstrap-класс `is-invalid`.
- При валидном `submit` вызывается `preventDefault()`: вместо обращения к отсутствующему backend выводится локальное сообщение. Ввод не записывается в хранилище браузера.
- Bootstrap обеспечивает основную сетку и оформление; `custom.css` содержит только небольшие дополнения. Стили из КР №1 не перенесены.
